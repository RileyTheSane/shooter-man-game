## How To Play
WASD / Arrow Keys - Movement<br />
Space / Left Click - Shoot<br />
Use [this link](https://rileythesane.itch.io/shooter-man-game) to play the game on itch.io.

## About The Project
<br />
Gloinks are here to try and take down Bob once again. Can you defend him from the Gloinks?
<br />
Game Includes:<br />
- Home Screen<br />
- Backstory Cutscene<br />
- 9 waves of Glonks to fight off<br />
- A scoring system<br />
<p align="right"></p>

## Built Using
This project was made with the Godot game engine.
<p align="right"></p>

## AI User
I'm learning Godot and during the making of the game I used AI to figure out how to use the godot nodes and help me debug issues. As of now there isn't any AI generated code or images in the game's files.
